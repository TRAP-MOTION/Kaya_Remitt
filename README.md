# Kaya_Remitt
KayaRemit Hackthon project - Digital Remittance platform

KayaRemit is a web-based financial management platform designed to help individuals manage, track, and improve their financial decisions.

The platform provides users with tools for monitoring transactions, managing budgets, setting savings goals, and understanding their spending habits through a simple and organised dashboard.

KayaRemit aims to improve financial awareness and encourage better money management through accessible digital solutions.

## Project Status

Prototype under development.

## Main Features

-User authentication
-Financial dashboard
-Transaction tracking
-Budget management
-Savings goals
-Spending analytics
-User settings
